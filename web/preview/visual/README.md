# Orbit theme assets

Prepared 2026-10-07 for Tevumi's approved dark visual direction. Decorative images are generated with the built-in imagegen tool, optimized to WebP and rendered as noninteractive imagery. They are not partner endorsements or price data.

- `aurora-background.webp`: 1920×1440; dark teal aurora, quiet space behind controls.
- `buy-orbs.webp`: 768×640; BNB and abstract value artwork.
- `bridge-orbs.webp`: 768×640; BNB and Arc artwork.
- `swap-orbs.webp`: 768×640; Arc and USDC artwork.
- `usdc-orbs.webp`: 768×640; Arc and Base artwork. This is illustrative decoration; the destination picker remains authoritative for all supported routes.
- `tevumi-orbit.webp`: 410×410; derived from the user-requested crop of approved Orbit T concept `exec-fde556ca-a1b7-46d0-a035-04c72966a3c6.png`. Uses original opaque dark background; transparent extraction had visible edge artifacts and was not adopted.

Prompt direction: cinematic near-black teal, sparse stars, cyan light connections, dark mountains and reflected water, no UI, labels, prices or transaction identifiers. Brand icon geometry is the user-selected T with an open diagonal orbital ellipse. All existing operational UI icons and wallet controls are retained.

Artwork is hidden on narrow screens. The original `web/public/brand/tevumi.svg` remains available. No fonts or new packages were added; display headings retain Georgia and controls use the existing system font stack.
